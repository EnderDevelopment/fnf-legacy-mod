# FNaF Legacy Mod

FNaF Legacy Mod is a Minecraft plugin that immerses players in the dark lore of William Afton and Five Nights at Freddy’s. Players can craft iconic Spring Bonnie and Fredbear springlock suits, encounter roaming animatronics, and survive by monitoring security cameras and installing powered office doors.

## Install

1. Download the plugin JAR file from the releases section.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server.

## Use

1. To craft a suit, use the command `/craftsuit <suitType>`, where `<suitType>` is either `springbonnie` or `fredbear`.
2. Explore the world to encounter roaming animatronics like Puppet, Glamrock, and Nightmare.
3. Monitor security cameras and install powered office doors to survive.
